# Driver Confidence Guide (DCG)
## Project Overview

**Version 1.1.0**

## Purpose

The Driver Confidence Guide (DCG) is a practical learning resource designed to help people become more confident vehicle owners and drivers.

It is not intended to teach advanced automotive repair. Its purpose is to help ordinary people feel more comfortable using, maintaining, and caring for a vehicle in everyday life.

DCG addresses practical questions that experienced drivers may take for granted, including:

- finding the owner's manual
- understanding dashboard warning lights
- checking tire pressure
- refueling correctly
- connecting a phone to the dashboard
- knowing when to call for help

Confidence is built through small, manageable learning missions.

## Audience

DCG can help new and teen drivers, adults purchasing or regularly using a vehicle, parents helping a new driver, older adults returning to driving, and anyone who was never taught basic vehicle ownership skills.

## How to Use the Website

Visitors begin at the home page and browse the mission library. Each mission is a self-contained topic. A learner may choose a mission, view its illustrated pages, practice the task when appropriate, return later for review, and submit feedback about confusing or missing material.

The missions can be completed in sequence or selected as needed.

## Website Purpose

The DCG website is the learner-facing delivery system for the guide. It provides a home page and mission library, one folder for each published mission, illustrated mission pages, supporting informational pages, and a feedback page.

## Relationship to the Learning Adventure Method and ALS

```text
Learning Adventure Method

Driver Confidence Guide

```

- **The Learning Adventure Method** defines the educational approach.
- **Adventure Learning Studio (ALS)** is the authoring environment being developed to create and manage Learning Adventures.
- **DCG** is a learner-facing website and reference implementation.

DCG currently exists as a working published website. ALS is intended to make future creation, revision, preview, and publishing of projects like DCG more systematic.

## Summary

The Driver Confidence Guide is a practical Learning Adventure that helps people become more confident drivers and vehicle owners through small, achievable missions.
